<h1>Institute Gathering Scoring App</h1>

<b>Overview</b><br>
This application is designed to streamline scoring and result management for institute gatherings and events. It provides a centralised platform for updating scores, displaying leaderboards, and managing scoring presets with ease.

<b>Features</b><br>
Real-Time Updates: Utilises WebSockets to broadcast score changes instantly to all connected devices.
Leaderboards: Automatically generated leaderboards to keep participants and audiences informed of the latest standings.
Scoring Presets: Predefined scoring configurations to make score entry faster and more accurate.
Automatic Score Updation: Scores are calculated and updated automatically based on the selected preset rules.

<b>Usage</b><br>
Set up scoring presets for different events.
Use the interface to input and update participants’ scores.
Real-time updates ensure that the leaderboard reflects the current standings immediately.
Monitor the leaderboard during events for easy tracking of winners.

<b>Technology</b><br>
WebSockets: For live communication and real-time score updates.
Responsive UI: Optimised for multiple devices for easy access during gatherings.

<b>Purpose</b><br>
This app ensures smooth and transparent scoring for institute events, allowing organisers to focus more on the event itself while keeping participants and audiences engaged with live updates.
